# ระบบสต๊อกสินค้า

เว็บแอปสต๊อกสินค้าภาษาไทย ใช้งานได้ทันทีจากไฟล์ `index.html` โดยเก็บข้อมูลใน LocalStorage ของเบราว์เซอร์

## ฟังก์ชัน

- เพิ่ม/แก้ไข/ลบสินค้า
- เก็บบาร์โค้ด ชื่อสินค้า ราคาทุน ราคาขาย และจำนวนขั้นต่ำ
- ขายสินค้าและตัดสต๊อกอัตโนมัติ
- รับสินค้าเข้า
- รองรับเครื่องสแกนบาร์โค้ด USB/Bluetooth ที่ทำงานเหมือนคีย์บอร์ด
- รองรับการสแกนด้วยกล้องใน Chrome/Edge รุ่นที่รองรับ BarcodeDetector
- ดูประวัติการเคลื่อนไหวสินค้า
- สรุปยอดขายรายวันและกำไรขั้นต้นโดยประมาณ
- แจ้งเตือนสินค้าใกล้หมด
- ส่งออกประวัติเป็น CSV

## วิธีใช้

1. เปิดไฟล์ `index.html` ด้วย Chrome หรือ Edge
2. ไปที่แท็บ **สินค้า** แล้วเพิ่มสินค้าและบาร์โค้ด
3. เวลาได้รับสินค้า ให้ใช้แท็บ **รับสินค้าเข้า**
4. เวลาขายสินค้า ให้ยิงบาร์โค้ดที่หน้า **ขายสินค้า**
5. ระบบจะตัดสต๊อกและบันทึกประวัติให้ทันที

## หมายเหตุสำคัญ

เวอร์ชันนี้เก็บข้อมูลในเบราว์เซอร์ของเครื่องที่ใช้งาน จึงเหมาะสำหรับร้านขนาดเล็กหรือการทดลองระบบก่อน หากต้องการใช้งานหลายมือถือ/หลายเครื่องพร้อมกัน ควรต่อฐานข้อมูลส่วนกลาง เช่น Google Sheets, Supabase หรือ Firebase

## ขั้นต่อไปที่แนะนำ

- เชื่อม Google Sheets ให้หลายเครื่องเห็นข้อมูลเดียวกัน
- ระบบผู้ใช้งาน/พนักงาน
- เลขที่บิลและพิมพ์ใบเสร็จ
- รายงานยอดขายรายสินค้า
- สแกนบาร์โค้ดเพิ่มสินค้าอัตโนมัติ
- สำรองข้อมูลขึ้น Cloud
